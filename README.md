# Formik & Yup Validation Practice

This is a simple React project built to learn and practice form handling with **Formik** and schema validation with **Yup**.

## 🚀 Project Overview
* **Goal**: Understand how to manage form state and validate user inputs efficiently in React.
* **Core Tools**: Formik for form state management and Yup for data validation.

## ✨ Key Features
* Clean and simple form setup using Formik hooks or components.
* Real-time field validation and error messages powered by Yup schemas.
* Handling form submission, resetting values, and managing submit states.

## 🛠️ Tech Stack
* **React**: JavaScript library for building user interfaces.
* **Formik**: Library to handle form values, submission, and validation errors.
* **Yup**: Schema builder for value parsing and validation.

## 💻 Getting Started

To run this project locally, clone the repository and install the dependencies:

bash
npm install
npm start
